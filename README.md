# kontrolor-test

Офлајн квиз за самопроверу контролора на изборима. Један HTML фајл са уграђеном банком питања (74 питања после уклањања дупликата); при сваком учитавању извлачи се 42 питања са покрићем свих секција обуке.

## Локално отварање

1. Преузмите `index.html` (или клонирајте овај репозиторијум).
2. Двапут кликните на `index.html`, или отворите га у прегледачу (Chrome / Firefox / Safari / Edge).
3. Рад на `file://` је довољан — нема сервера, нема CDN-а, нема мрежних захтева.

Дугме **Пошаљи одговоре** приказује резултат и тачне одговоре. **Потврди поново** (или освежавање странице) извлачи нови скуп.

## Google Drive

1. Отпремите само `index.html` на Drive.
2. Поделите линк са колегама.
3. Ако Drive преглед блокира JavaScript (често), корисник треба: **Download → отворити локално** у прегледачу.

`question-bank.json` је у репозиторијуму ради прегледа банке; за дељење на Drive довољан је HTML (банка је уграђена).

## Садржај

| Фајл | Опис |
|------|------|
| `index.html` | Самостални квиз (UTF-8 ћирилица) |
| `question-bank.json` | Очишћена банка (74 питања; без Q66/Q72) |
| `PLAN.md` | Спецификација v1 |
| `README.md` | Овај фајл |

Види `PLAN.md` за правила извлачења, дедупликацију и тест чеклисту.
